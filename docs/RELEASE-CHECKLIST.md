# Проверка перед стабильным релизом

Текущая сборка: **Zornhau 0.8.3**, Vintage Story **1.22.7**.
Это тестовая сборка. Автоматические проверки не заменяют записанный прогон
двух игровых клиентов; отсутствие сообщения о баге не считается его проверкой.

Прыжки доступны в бою: перемещение по блокам остаётся необходимой частью игры.
Во время реза ограничиваются направление персонажа и разворот модели тела.
Свободная камера F5 сохраняет независимое вращение. Замах, блок и возврат
сохраняют свободный разворот. Спринт после удара ограничен прежними правилами.

## Автоматические проверки

- [x] Регрессия F5 на настоящем `ClientMain.UpdateCameraYawPitch`: все три режима,
  движение без мыши, разные FPS/сглаживание, прыжок и переключение камеры в резе.
- [x] Разворот модели через настоящий `PlayerHeadController`, сброс остатка мыши.
- [x] Серверная проверка углов через настоящий декодер движения и оба протокола
  контакта; дубли/старые сообщения, общий бюджет yaw/pitch, отдельный BodyYaw,
  нечисловые значения и спам без дополнительного углового запаса.
- [x] Вход в реалистичное первое лицо, модели щитов, прерывания ударов/лечения/лука.
- [x] Обычная сборка всегда импортирует сохранённые авторские анимации.
- [x] Архив 0.8.3 запускает изолированные миры с CO и без него; игровой
  болванчик проходит спавн, смерть и восстановление. Natural Motion проходит
  собственный прогон совместимости.

Команды проверки полного архива:

```bash
bash scripts/build.sh
bash natural-motion/build.sh
python3 scripts/audit-balance.py --smoke --training-smoke
```

## Обязательные игровые прогоны

Для каждого прогона записать версии/конфиг, дату, участников, пинг, результат
и лог F8 для спорных контактов. Использовать одну неизменную сборку и одинаковые
настройки на обоих клиентах. Менять роли и оружие между участниками.

| Прогон | Что должно выполняться | Результат |
| --- | --- | --- |
| F5 и движение | Камера свободна, персонаж не вращается мгновенно в резе; движение и прыжок сохраняются; выход из реза не воспроизводит старый ввод | Не проведён |
| Граница замаха/реза | Быстрый свободный разворот перед выпуском не приводит к ложной отмене обычного удара сервером; проверить обычный пинг и джиттер | Не проведён |
| Два игрока | Быстрый блок, финт, одновременные удары, смена слота/хвата, удержание кнопок; один урон на удар и сохранение восстановления | Не проведён |
| Обходные действия | Баш/удары рукоятью, стрелы/метание, взаимодействия с блоками и трупами не дают обхода обязательного PvP или двойного урона | Не проведён |
| Броня | Торс и открытые зоны, смешанные слои, износ, качество/закалка; отдельно зафиксировать настройку второго шанса CO | Не проведён |
| Лечение и лук | Удар прерывает применение; готовое лечение тикает; прерванная стрела/бинт не расходуется; требуется новая попытка | Не проведён |
| Камера и экипировка | Вход/перезаход, три F5-режима, реалистичное FP, щиты game/Armory, смерть/возрождение и вид наблюдателя | Не проведён |
| Затяжной бой | Кинжал/двуручник, щит/двуручник, булава/латы, копьё/меч; записать блоки, попадания, износ и длительность | Не проведён |
| Нагрузка | Несколько одновременных боёв/добиваний: время тика, FPS, память; повторные подключения, сохранение и перезапуск мира | Не проведён |

Проверяемые связки: самостоятельный Zornhau; закреплённый набор CO/Armory из
`compat/overhaul-modpack.json`; обе связки с Natural Motion 0.1.11.
Конный бой отдельным поддерживаемым режимом этого релиза не объявляется.

## Выпуск

- [ ] Исправления F5/щита/камеры подтверждены игровым прогоном.
- [ ] Броневой баланс и второй шанс CO утверждены по дуэлям, включая дальний бой.
- [ ] У согласованной серверной нагрузки нет роста памяти и устойчивого превышения
  бюджета тика; сохранение/перезапуск не теряют предметы и состояние мира.
- [ ] Исходники зафиксированы коммитом; архив собирается из чистого клона.
- [ ] Указана лицензия основного мода и сохранены лицензии встроенных компонентов.
- [ ] Зафиксированы тег, хеши архивов, поддерживаемые версии и инструкция обновления;
  на клиенте и сервере остаётся по одному архиву Zornhau.

Полного серверного воспроизведения позы/траектории клинка нет: угловой бюджет,
дальность, препятствия и состояние атаки проверяют правдоподобие клиентского
контакта. Это ограничение необходимо учитывать для публичного PvP.
Новые территории/осады и дополнительные боевые механики имеют отдельные этапы.
