# Редактирование боевых анимаций

Открыть: ярлык «VS — редактор боевых анимаций» или `bash scripts/edit-animations.sh`.
Файл: `editor/seraph-combat.json`. Он содержит отдельную копию персонажа, меч для просмотра и наши 32 клипа.

После доработки начальных кадров редактор и установка по умолчанию используют
`editor/seraph-combat-completed.json`, если этот файл существует. Исходное авторское
сохранение `seraph-combat.json` сохранено отдельно. В доработанной копии четыре блока
удерживают начальные позы, боковые замахи согласованы с первыми кадрами ударов,
а варианты от первого лица повторяют эти движения.

`seraph-combat-thrust-wip.json` сохраняет доработанный укол из 0.2.3 для дальнейшего
разбора проблемы с камерой. По умолчанию он не устанавливается; текущая игровая
копия находится в `seraph-combat-completed.json`.

1. Справа нажми вкладку **Keyframe**. Слева выбери анимацию.
2. `warband-windup-left` / `warband-windup-right` — удерживаемые боковые замахи.
   `warband-swing-left` / `warband-swing-right` — движение удара.
   `warband-recovery-*` — возврат. Варианты `-fp` используются от первого лица.
3. Выбери кадр на шкале и элемент в дереве справа:
   **UpperArmR** — плечо, **LowerArmR** — предплечье, **ItemAnchor** — поворот меча в кисти.
   **UpperTorso**, **Neck**, **Head** — корпус, шея, голова.
4. Включи редактирование **Rotation** для кадра и меняй X/Y/Z. Кнопка проигрывания показывает движение.
5. Сохрани **Ctrl+S** в этот же файл. Имена клипов и элементов оставляй прежними.

Меч `PreviewSword*` нужен для просмотра. Поворачивай **ItemAnchor**, чтобы этот поворот попал в игру.
Не сдвигай плечо полями Position: оно отрывается от корпуса. У замаха одинаковые кадры 0 и 14;
для неподвижного удержания меняй оба. Переход удара в возврат: кадр 4 swing соответствует кадру 0 recovery.

После изменения только начальной позы `warband-swing-thrust` можно доработать укол командой
`python3 scripts/complete-editor-animations.py --thrust-only` при закрытом редакторе.
Она сохраняет первый и последний кадры, выстраивает движение к конечной позе на кадре 4,
согласует удерживаемый замах и вариант от первого лица. До записи сохраняется резервная
копия в `.artifacts/editor-backups`. Остальные направления и блоки остаются авторскими.

Чтобы попробовать изменения, выйди из игрового мира, затем в терминале проекта выполни:

```bash
bash scripts/install-editor.sh
bash scripts/play.sh --openWorld 'vintage freestyle world'
```

Сборка сначала проверяет исходные анимации, затем проверяет формат и импортирует сохранённые клипы.
Авторские позы не ограничиваются исходными проверками геометрии. Обычный `scripts/install.sh`
устанавливает анимации из генератора; сохранённый файл редактора при этом остаётся на месте.
