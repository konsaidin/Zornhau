# Natural Motion 0.1.11

Отдельный клиентский мод для **Vintage Story 1.22.7**. Согласует анимации движения
со скоростью и звуками шагов, сохраняет хват оружия при ходьбе, беге и прыжках.
Работает самостоятельно; Zornhau, Combat Overhaul и Armory не обязательны.

## Возможности

- Боковые, обратные и диагональные шаги используют соответствующие штатные клипы.
- Частота шагов и махи рук с обычными предметами согласованы с движением.
- В прыжке руки переходят в удерживаемую позу вместо наземных махов;
  ноги проходят толчок, полёт и плавное приземление. Ведущая нога чередуется.
- При движении вбок таз плавно разворачивается; торс и голова компенсируют поворот.
- С оружием или щитом подавляются махи обеих рук и качание родительских костей,
  которые нарушают хват. Оружейные позы, атаки, блоки и движения взгляда сохраняются.
- Поддерживаются собственный персонаж и другие видимые игроки, обычное и
  реалистичное первое лицо, а также третье лицо.

## Установка

Скопируй `naturalmotion-0.1.11.zip` в `Mods` клиентского профиля и полностью
перезапусти игру. Серверу мод не требуется. Чтобы видеть исправления,
каждый клиент устанавливает его у себя.

Natural Motion не входит в архив Zornhau. Распознавание боевых состояний совместимо
с ID `zornhau`; одноручные и двуручные хваты CO/Armory используют оружейные позы
вместо обычных махов рук. Другие моды, меняющие те же кости или локомоцию,
могут потребовать адаптации. Для моделей без нужных штатных клипов исправления
не включаются.

## Сборка и проверки

Из корня репозитория, с .NET SDK 10 и установленной игрой:

```bash
export VSPath="$HOME/Documents/vintagestory"
bash scripts/build.sh
bash natural-motion/build.sh
```

Основная сборка загружает совместимые CO/Armory-фикстуры для проверок хвата.
Архив отдельного мода создаётся в `natural-motion/dist/`.
`VS_DOTNET` выбирает SDK; подробности — в [руководстве разработчика](../docs/DEVELOPMENT.md).
Мод читает скелет и клипы из установленной игры; игровые модели не входят в его ZIP.

## Настройки

После первого запуска создаётся `ModConfig/natural-motion.json` в профиле.
Изменения применяются после перезапуска игры.

| Настройка | По умолчанию | Значение |
|---|---:|---|
| `Enabled` | `true` | Включить исправления |
| `DirectionalSteps` | `true` | Боковые, обратные и диагональные шаги |
| `AirbornePose` | `true` | Толчок, полёт, чередование ног и приземление |
| `SyncFootsteps` | `true` | Подстройка анимации к штатным звукам шагов |
| `WalkStepMilliseconds` | `470` | Базовый интервал одного шага при ходьбе; 150–1500 мс |
| `SprintStepMilliseconds` | `340` | Базовый интервал одного шага при беге; 150–1500 мс |
| `WalkStepScale` | `1.35` | Размах ног при ходьбе относительно штатного; 1–1.65 |
| `JumpLegHeight` | `0.55` | Подъём и сгибание ног в прыжке относительно прежнего; 0.25–1 |
| `BodyTurnDegrees` | `28` | Максимальный поворот таза; 0–40°, 0 отключает |
| `WalkStride` | `1.65` | Метры на цикл при выключенном `SyncFootsteps`; 0.6–3 |
| `SprintStride` | `2.3` | Метры на цикл переднего бега без `SyncFootsteps`; 1–4 |
| `Response` | `12` | Скорость сглаживания; 4–24 |

## Проверка в игре

Пройди вперёд, назад, A/D и по диагоналям, затем проверь бег, прыжок на месте,
прыжок в движении и приземление. Повтори с пустыми руками, обычным предметом,
одноручным оружием, двуручником и щитом во всех трёх режимах камеры.

Автоматические проверки охватывают разные FPS, настройку шагов, переходы
земля/воздух, телепорты, настоящий скелет и обработчики поз CO. Визуальное
качество переходов нужно оценивать в игре.
