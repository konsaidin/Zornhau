# Неткод и PvP — аудит 0.7.8

Локальные замах, выпуск удара, блок, звук взмаха и ограничение бега предсказываются
сразу. Урон, парирование, прерывание атаки, износ и добивания подтверждает сервер.
Пинг не исчезает: подтверждение контакта требует доставки пакета; при потере
связи, сильной асимметрии или большой задержке коррекции остаются необходимыми.

## Исправления

| Проблема | Поведение 0.7.8 |
|---|---|
| Серверная коррекция принималась только при точном совпадении с последним номером ввода. Heartbeat зажатой кнопки мог постоянно делать её «устаревшей» | Каждый снимок имеет отдельную возрастающую ревизию. Клиент восстанавливает подтверждённое состояние и повторно применяет ещё не подтверждённый ввод |
| Старое подтверждение могло снова разрешить контакт уже завершённого локального взмаха | Завершённый контакт сохраняется для того же ID атаки, в том числе после повторного применения Release. Новая атака получает новый ID |
| Контакт CO не содержал номер нашей атаки | Нативный protobuf обёрнут в пакет Warband с ID атаки. Непривязанный, повторный или чужой контакт не получает разрешения на урон |
| Парирование могло не корректировать клиента с вводом в пути; его длительность проецировалась назад на полный RTT | Коррекция проходит при старшем подтверждении ввода; для событий сервера используется оценка доставки в одну сторону — половина измеренного RTT |
| Попадание по игроку не прерывало атаку | Реальный, не отражённый урон нашей ближней боёвки прерывает замах или выпущенный удар. Минимальное восстановление 240 мс, уже назначенное более долгое восстановление сохраняется |
| Контакт после сжатия очереди из-за джиттера приходил чуть раньше серверного конца замаха и терялся | Один контакт можно сохранить до начала удара, максимум на 75 мс. Все проверки повторяются при обработке; урон раньше полного замаха не проходит |
| Дальность проверялась от текущей позиции атакующего, хотя клинок был показан раньше | Для атакующего используется та же ограниченная история настоящих серверных позиций, что и для цели. Дальность оружия не увеличивается |
| Смена наличия щита отменяла первый восстановленный блок наблюдаемого игрока | Состояние экипировки применяется перед восстановлением удалённой позы |
| Компенсированное попадание в голову сравнивалось только с текущей позицией жертвы | Головная зона проверяется по той же ограниченной истории. Смертельный источник и правило бокового рубящего удара сохраняются |

## Что остаётся серверным

Клиент не задаёт урон, время начала серверного замаха или его длительность.
Сервер сверяет оружие, режим, обе руки, слот, фазу, ID атаки, цель, измерение,
права PvP, конечность координат, дальность и препятствия. В самостоятельном
моде дополнительно проверяются длина сегмента клинка и точка внутри его sweep.
CO сохраняет свою проверку типа урона и экипировки. Нативные пакеты атак,
push и статусов CO для принадлежащих Warband оружий/щитов не обходят этот путь.
Нативный push в закреплённой библиотеке уже является пустой операцией.

История не переживает телепорт, смену измерения или разрыв отслеживания.
Проверка препятствий остаётся относительно текущего мира: это сознательный
предел компенсации, а не разрешение бить через стену из старого положения.
Заблокированный или полностью поглощённый урон не прерывает противника.
Уже нанесённый урон не отменяется при более позднем получении собственного удара.

## Проверки и оставшиеся ограничения

`tests/server/NetcodeChecks.cs` использует производственный обработчик коррекций
и две отдельные серверные сессии. Матрица из 108 сценариев:
RTT 0/30/80/150/300/600 мс × джиттер 0/30/75 мс × 30/60/144 FPS ×
короткий клик / удержание 1,2 с. Очереди сохраняют порядок доставки,
обработка сервера квантуется по 20 мс. Проверяются подтверждения при вводе
в пути, остаток восстановления, отсутствие повторного контакта, ID атаки,
прерывание от настоящего урона, ранний буфер, предел журнала, обёртка protobuf,
движение и телепорт. Это симуляция обработки пакетов, а не эмуляция транспорта
с потерей пакетов и не проведённая живая дуэль двух клиентов.

Отдельно проверяются штатные блоки и hurt-анимации, физические коллайдеры,
все режимы оружия, добивания и загрузка изолированного сервера с CO / без CO.

Движение чужих персонажей и транспорт принадлежат движку Vintage Story.
Асимметричная задержка не определяется одним RTT; оценка половины RTT может
потребовать коррекции. Длинный сетевой провал может оборвать удержание,
а контакт после серверного конца реза отклоняется. История позиций не является
полным откатом всех костей, брони и блоков мира; сервер проверяет правдоподобие
показанного клиентом физического контакта, а не пересчитывает всю отрисовку.
Полноценный античит для изменённого клиента и историческая проверка каждого
сустава остаются отдельными задачами.

Для оценки ощущения нужны живые дуэли при обычном пинге обоих игроков:
быстрый блок, финт, одновременные удары, движение в стороны и бой около стены.
F8 показывает часть тела, направление, тип урона и факт смертельного контакта;
отладка по умолчанию выключена.
